2. 按层次深入：SOL → 子系统分析 → 具体指标 → 根因

**路径 C：完整框架**

### Step 3：讲解规范

**每个概念必须包含：**

## 讲解示例（SOL 指标）

用户："sm__throughput 是什么意思，99% 是好事吗？"

正确回答框架：
1. **硬件对应**：测量 SM（流多处理器）的计算吞吐达到理论峰值的百分比
2. **计算方式**：(实际指令执行速率) / (理论峰值指令速率) × 100%
3. **正常范围**：>80% 说明 Compute-Bound；99% 是优秀的计算利用率
4. **类比**：就像工厂的机器开动率——99% 说明机器在全力运转
5. **追问**：但同时要看 `dram__throughput`——如果内存也是 99%，说明同时达到了两个瓶颈（不太可能），更可能的是 Compute 在等内存，表面的 99% 是被内存延迟撑起来的
